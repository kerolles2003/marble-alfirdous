# معرض الفردوس — رخام وجرانيت

موقع معرض الفردوس للرخام والجرانيت: مطابخ، حمامات، أبواب، طاولات، وتفصيل من الورشة.

## الصفحات

- `index.html` — الرئيسية
- `about.html` — من نحن
- `services.html` — خدماتنا
- `gallery.html` — معرض الأعمال (20 صورة + فلاتر)
- `videos.html` — فيديوهات من الشغل
- `contact.html` — تواصل معنا (الفورم بيبعت على واتساب)

## النشر

الموقع ستاتيك بالكامل (HTML/CSS/JS) ومربوط على Vercel بالريبو ده — أي push على فرع `main` بينشر الموقع لايف أوتوماتيك.

- الإدارة: م/ بولا إبراهيم — 01121466648 / 01067381671، م/ بيتر إبراهيم — 01116223461 / 01034038208 (كل الأرقام واتساب ومكالمات)
- العنوان: طريق مصر إسماعيلية، منتجع أمنحتب، بجوار سوق العبور
- الفيديوهات: بتتضاف من مصفوفة `YOUTUBE_VIDEOS` في `assets/js/site.js` (لينك يوتيوب كامل لكل فيديو).
